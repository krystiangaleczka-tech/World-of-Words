# T-0243 navigation P2

Base d89b11a / merged T-0242. Explicit navigation P2 routes returning players from committed saved
slot to Home at journey_slot, preserving terminal-slot routing before Level clamping. History
restores screen/slot and revalidates Content. Save/Config/Content loading and screen transitions
reject reentrant routes. Invalid/departed hosts cannot navigate, background or display pending
messages. Replacing service identities resets navigation state to P1; same identities preserve it.

Before leaving a campaign Level, its actual local Progress persists the board or retries a pending
P1 completion before the screen is destroyed. Save failures retain screen/history and block
backgrounding. Back reevaluates Home availability after a durable completion retry. Historical
Debug boards cannot overwrite campaign state. Native Back consults same-viewport Sheet first;
standalone Sheet handling stays unchanged. Background uses built-in AndroidRuntime Activity
moveTaskToBack, with an injected deterministic test callable and no quit/permission/plugin fallback.

Transitions use existing Tokens, restore process mode and release owned tweens on host/owner exit.
One reusable Toast drains pending pairs on Home, inherits its theme/safe-body context and parks
hidden in Nav's layer before screen destruction. Host loss retains unpresented messages; changing
service identity or destroying Nav disposes old callbacks/messages safely. Backup restore wiring
is owned and disconnected; purchase copy is only a future explicit enqueue seam, with no SDK call.

No automatic atomic gameplay/Progress/Economy activation, save schema, economic values/providers,
config/content, analytics schema, autoload or project/export changes. Home/Journey/Postcard scene
content remains T-0244–0246; current missing scenes are empty routing states, not completed UI.
