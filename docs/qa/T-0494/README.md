# Shorter islands in the ranked Polish preview

| Map page | First island range | Last island range |
| --- | --- | --- |
| 1 | 1–25 | 76–100 |
| 2 | 101–150 | 251–300 |
| 51 | 9901–9950 | 9951–10000 |

The first four islands cover 25 levels each. The subsequent 198 islands cover 50 each. The prior illustrations form four repeating themes. Each island starts its own three-view sequence, and each successive level changes the illustration.

Use the staging and smoke commands in [T-0493](../T-0493/README.md#build-and-verify). The smoke script walks all 51 pages, checks the artwork and slot assignment of all 10,000 levels, solves the opening puzzle, and checks the saved route after a restart.
