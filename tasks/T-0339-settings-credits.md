## Goal
Provide Settings with all current engine/asset/content notices in exportable
resources, preserving exact upstream legal text. This is the independently
executable catalog portion split from ROADMAP T-0288 under the Phase-2 rolling-wave
rule; T-0288's screen and store/privacy/support actions remain open.

## Context
- docs/PRODUCT.md#fr-set-settings: FR-SET-03 requires engine and third-party credits.
- docs/decisions/0008-pl-word-sources.md: selected PL sources need attribution,
  modification statements and the Morfeusz/SGJP BSD notice.
- Existing font/icon resource metadata intentionally preserves full source notices.

## Current state
- game/assets/fonts/font_license.tres metadata/ofl_notice and
  game/assets/icons/icon_license.tres metadata/license_notice are exportable.
- game/assets/audio/p1/NOTICE.md and game/content/NOTICE hold complete current
  audio/PL source notices; raw Markdown/NOTICE files are not included by the
  existing all_resources export. No runtime credits catalog exists.
- Engine.get_license_text(), get_copyright_info() and get_license_info() expose
  this exact engine build's licence, third-party copyright data and full texts.
- Existing CI exports and inspects actual Android Release resources.

## Specification
1. Add SettingsCredits extends RefCounted, static entries() -> Array[Dictionary].
   Seven ordered entries with id:StringName and notice:String: godot,
   godot-copyrights, godot-licenses, inter, lucide, audio, pl-sources.
   Engine notice is verbatim get_license_text(); copyright entry preserves ALL
   get_copyright_info data as indented JSON; license entry joins sorted licence
   names and their full texts. Legal data stays in original language; no screen,
   visible title, translation, navigation or browser action is introduced.
2. Read existing font/icon resource metadata verbatim. Add exportable generic
   Resource .tres metadata/notice for audio and content, generated byte-for-byte
   from their current canonical UTF-8 NOTICE files. Never shorten/discard their
   modification statements, source pins, copyright or disclaimers. Do not alter
   source notices, engine, export settings, content JSON or registries.
3. Standard-library tools/generate_credits.py writes only the two known output
   resources; --check detects missing/stale files without modifying them. Script
   callable from any working directory. Automated tools tests enforce drift check
   in existing make check/CI. No runtime reading of raw source files.
4. Every entries() call returns fresh containers; mutations cannot corrupt later
   calls or Engine data. No I/O, global state, singleton or Node lifetime to manage.
5. This catalog reflects current shipped assets/content. No native SDK is enabled;
   native adapter activation and final asset/source changes must add their notices
   before release. Do not invent SDK licences or certify production compliance.
   Fullscreen licences UI and T-0288 external integrations remain separate gates.

## Tests
- GUT verifies exact seven IDs/order, nonempty notices, exact engine licence and
  entire copyright JSON, all engine licence texts, exact font/icon metadata, exact
  canonical audio/content notice text, modification/attribution/disclaimer presence,
  deterministic snapshots and mutation isolation.
- Python generator tests verify exact UTF-8 metadata serialization, actual tracked
  outputs current, missing/stale detection without mutation, regeneration and CLI
  invocation outside the repository.
- Full make check; fresh independent review; exact-head CI including both Android
  jobs. Download actual Release content archive and verify all four notice
  resources/remaps and the compiled catalog are present, then record PR evidence.

## Acceptance
Current legal texts remain available offline in exports without raw text include
filters. All stated tests pass. T-0288 UI/actions and native/legal release gates
are explicitly open; no completed UI or native SDK claim.
