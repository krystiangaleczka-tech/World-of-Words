## Goal
Select and classify Polish candidate crossword arrangements for proposed slots 66–200,
preserving the existing 65-level P1 campaign and every native word-eligibility rule.
Provide a reviewable, evidence-bound 200-slot inventory rather than claiming a P2
production release before T-0297–T-0305 and native gameplay review finish.

## Source and existing state
- ROADMAP.md T-0306: production build slots 1–200; handmade onboarding 1–15,
  first region with 3–4 locations. This preparation does **not** satisfy that release gate.
- CONTENT.md#word-tiers / FR-CONT-05: dictionary + overrides are the sole eligibility
  authority. The game ships no runtime dictionary.
- CONTENT.md#p1-repetition-spacing: at least 100 slots between reoccurrences of any
  crossword answer. Released-slot rules remain unmodified.
- `game/content/pl/manifest.json`: currently 65 shipped slots.
- `pipeline/content-inputs/pl.json`: pinned compact P1 source-tier extract, carrying
  649 level_ok forms. Its scope is finite and is not the full future source dictionary.
- `pipeline/src/wordgame_pipeline/grid/__init__.py:make_level` and geometry checks
  accept authored placements and generate all source-backed bonus words.
- T-0359 sequence allocator and T-0300 scoring are review/unactivated; no production
  calibrated score, 200-slot exporter, or authored region metadata is yet certified.

## Owner-directed bounded preparation (2026-10-29)
Chris requested explicit word selection, difficulty grouping and preparation of the
200-level campaign. The 65 existing levels are preserved; slots 66–200 are now proposed.
This authorizes source-backed offline authoring and native validation, **not**
fabricating owner lexical acceptance or bypassing the still missing T-0303/T-0305.

## Proposed difficulty bands
- Existing 1–30 very easy, 31–65 easy (unchanged).
- Slots 66–90: editorial band 2, five wheel letters.
- Slots 91–150: band 3, six wheel letters.
- Slots 151–175: band 4, seven wheel letters.
- Slots 176–200: band 5, seven wheel letters, with extra answer combinations when
  source-backed and geometrically possible.
These are provisional curriculum bands, **not** calibrated numeric difficulty scores.

## Deliverables in this preparatory revision
1. Immutable, canonical task-specific JSON review inventory for slots 66–200, with
   per-slot wheel letters, selected crossword answers, explicit grid placements,
   provisional editorial band and manual-review priority flag.
2. Existing first 65 levels are not regenerated, changed, reclassified, or moved.
3. Every selected answer is a `level_ok` form from the pinned compact extract;
   no LLM/API lookup, source promotion, new word or override.
4. 100-slot minimum crossword answer spacing across the old and new levels, unique
   wheel multisets across all 200, and every selected word formable from wheel tiles.
5. Strict tests replay all 135 candidate grids via the existing native
   `make_level` and source WordIndex. Source and existing pack Git blob hashes
   are pinned in the candidate inventory; tests must fail on drift.
6. Bonuses remain derived from the full source pool by native code; none are typed
   manually in the proposal.
