## Acceptance
- `.github/workflows/ci.yml` runs on every pull request and on pushes to `main`.
- Jobs run in `ghcr.io/krystiangaleczka-tech/world-of-words-toolchain:latest`.
- Separate jobs run `make fmt-check`, `make lint`, `make test`, and `make tools-test`.
- `make pipeline-test` runs only when the change set contains a path under `pipeline/**`; otherwise
  the job prints an explicit SKIP reason and succeeds.
- The Godot test job always prints `/tmp/wow-godot-import.log` at the end, including after failures,
  so import errors and warnings are visible in CI output.
- CI on the task PR is green.
